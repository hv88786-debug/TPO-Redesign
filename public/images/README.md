Recruiter logos, campus photography, and OG images go here, organized
into `gallery/`, `recruiters/`, `students/`, `college/`.

Read `ASSET_GUIDE.md` before adding any file — it defines required
sizes, aspect ratios, naming convention, compression targets, and the
alt-text strategy for each folder.

Use next/image with explicit width/height (or `fill` + a sized parent) —
never a bare <img> tag.
