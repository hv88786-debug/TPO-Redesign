Recruiter logos referenced by `constants/recruiters.ts` (`logoSrc` field).

Use only logos provided directly by the recruiter or downloaded from
their official press/brand-assets page — do not screenshot logos from
other placement websites. Naming and sizing: see `../ASSET_GUIDE.md`.

Until a company's logo file is added here, its card falls back to a
monogram badge automatically — no component change is needed either way.
